# format:  <char>|<row0>/<row1>/<row2>/<row3>/<row4>/<row5>/<row6>/<row7>
# '#' = ink, '.' = empty. Space character is written as "space".

# design rules - keep these when editing, they are what makes mixed text look even:
#   capitals      rows 0..6   (row 7 stays empty)
#   lowercase     x-height rows 2..6
#   ascenders     b d f h k l t start at row 0 (t at row 0 with a row-6 tail)
#   descenders    g j p q y carry their tail into row 7
#   baseline      row 6 for every letter and digit
#   stroke        exactly one pixel, never two - heavy letters read as "cheap"
